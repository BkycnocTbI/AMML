# AMML Ranking Competition 2026

Решение для ранжирования русскоязычных фрагментов внутри запроса. Выбранный ансамбль получил **0.936737 Public NDCG@10**. В обучающей выборке 31 530 пар для 3 042 запросов, в тестовой — 13 507 пар для 1 305 запросов. Для дообучения использованы только пары соревнования. [Отправки на Kaggle](https://www.kaggle.com/competitions/amml-ranking-competition-2026/submissions)

## Итоговая модель

Замороженные Qwen3-Reranker-4B и BGE оценивают пары запрос–фрагмент. Списочная модель использует эти оценки, BM25, покрытие слов запроса и метаданные фрагментов. Её оценка составляет 85% опорной смеси, остальные 15% даёт отдельно дообученный BGE.

Контекстный BGE сравнивает представления всех кандидатов запроса через слой внимания. Веса внимания учитывают, лежат ли фрагменты в одной статье и насколько близки их позиции. На полном обучающем наборе модель обучается две эпохи с двумя начальными состояниями генератора случайных чисел. Её усреднённая оценка составляет 30% смеси с опорной моделью.

Отдельный BGE учится на полных фрагментах и окнах вокруг слов запроса. Используются усреднённые предсказания двух экземпляров после первой эпохи. Вес этого BGE в итоговой смеси растёт от 0,21 до 0,70 в зависимости от доли фрагментов длиннее 900 символов внутри запроса. Перед смешиванием оценки стандартизируются внутри запроса.

## Эксперименты

Фолды сформированы по `query_id`. Веса и эпохи выбирались по первым трём фолдам. Четвёртый использован для контрольной проверки. При равных оценках фрагменты сортируются по строковому `id`, запрос с нулевым IDCG получает 0.

| Модель | NDCG@10 на 1 520 общих отложенных запросах | NDCG@10 на 4-м фолде |
|---|---:|---:|
| Опорная смесь | 0.943683 | 0.938733 |
| Добавлен контекстный BGE | 0.945238 | 0.939763 |
| Добавлен BGE с окнами | **0.947257** | **0.941916** |

После добавления окон публичная метрика выросла с 0.936248 до 0.936737. В следующем эксперименте попарное уточнение топ‑3 с Qwen 8B подняло NDCG@10 на 1 520 отложенных запросах до 0.947651 и уступило ансамблю с окнами по публичной метрике Kaggle. Для воспроизведения выбран ансамбль с окнами. [Сравнение с Qwen 8B](https://www.kaggle.com/code/bkycnoctb/amml-top-three-final-ranking/log?scriptVersionId=371348730)

## Воспроизведение

Импортируйте `solution.ipynb` в Kaggle Notebook и подключите данные соревнования. Выберите **GPU T4 x2**, включите Internet для загрузки весов и запустите **Save & Run All**. Ноутбук вычисляет признаки, дообучает модели и формирует `/kaggle/working/submission.csv` в одной сессии. В конце он сверяет столбцы и порядок `id` с шаблоном, проверяет конечность оценок и выводит SHA-256 файла.

Версии в `requirements.txt` соответствуют окружению Kaggle Linux с Python 3.13.16 и PyTorch CUDA 13.0. Если окружение нужно собрать вручную, установите зависимости командой `python -m pip install -r requirements.txt`. Ноутбук выводит версии при запуске. Ревизии весов закреплены в коде.
